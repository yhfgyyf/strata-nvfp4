# Default data

- `checkpoint-manifest.json`: filenames, sizes and hashes for the pinned NVIDIA revision.
- `expert-profile.bin`: ranking and slot mapping for 48 × 512 experts; no model weights or conversation text.
- `draft_vocab.bin`: the Chinese/English draft token ID subset used for the measurements; no model weights.

The two binary files are the ones used for the README throughput table. Regeneration commands are in docs/INSTALL.md.
